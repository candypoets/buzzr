# bees-v1

Twenty-four profile avatars generated in Recraft with `recraftv4_1`, six per
collection. The original 1024×1024 results were reviewed as contact sheets,
then distributed as stripped 512×512 WebP files. Buzzr chooses one from the
manifest deterministically from the agent's random Nostr public key.

## Prompt set

Every prompt requested one centered, head-and-shoulders anime bee mascot with
large expressive eyes, antennae, a plush rounded body, visible translucent
wings, a clean silhouette, polished cel shading, generous square padding, a
simple graphic background, and no humans, extra creatures, text, logos, or
watermarks.

- **Sunforge:** honey, amber, orange, and cream; glasses, flight goggles,
  engineer caps, headsets, scarves, and tool pins.
- **Moonwire:** indigo, violet, electric blue, cyan, and silver; headphones,
  astronaut visors, star clips, hoods, luminous goggles, and antenna rings.
- **Mossbyte:** jade, mint, teal, lime, and warm yellow; botanist caps, leaf
  clips, field goggles, bandanas, mushroom berets, and compass pins.
- **Rosycore:** coral, cherry pink, magenta, lavender, and warm gold; berets,
  ribbon bows, heart-shaped goggles, headphones, star earrings, and scarves.

The images are generated assets. Check the repository license and Recraft's
applicable usage terms before redistributing the pack separately from Buzzr.
